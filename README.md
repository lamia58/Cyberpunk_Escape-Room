# Cyberpunk_Escape-Room
A simple Python text-based adventure game where the player is a hacker trying to escape a security facility. The player chooses a door and enters a passcode to escape. This project uses variables, user input, type casting, if/elif/else statements, and f-strings.

# Cyberpunk Escape Room

## Project Description
This is a simple text-based adventure game created using Python. The player acts as a hacker who is trapped inside a security facility and must find a way to escape.

## How the Game Works
1. Enter your hacker name.
2. Choose between the Red Door and Blue Door.
3. Enter the correct passcode to unlock the door.
4. Escape the facility or get caught by security drones.

## Python Concepts Used
- Variables
- User Input (`input()`)
- Type Casting (`int()`)
- If, Elif, Else Statements
- Comparison Operators (`==`)
- F-Strings

## How to Run
1. Open the Python file in VS Code.
2. Run `python cyberpunk_escape.py`.
3. Follow the instructions on the screen.

## Purpose
This project helped me practice basic Python programming, user input, and conditional statements.
